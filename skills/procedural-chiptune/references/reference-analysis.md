# 从参考到可用事件谱

## 分析输出该怎样读

`analyze_reference.py` 是本次整理的新辅助工具，把已有分析方法变为可移植入口；它不是历史上所有临时分析脚本的原样副本。解码得到 22050 Hz 单声道，再用两个时间／频率尺度分析：

- 2048 点 STFT、256 点步长：对数频谱正向变化形成 onset 包络，去掉慢变化，按滞后自相关给出 BPM 候选。强弱拍可能导致半速／倍速混淆；候选 periodicity 不是准确率。
- 8192 点 STFT、1024 点步长：局部谱白化抑制宽频音色包络，对前八个谐波加权，得到 可配置音域的候选显著度（默认 MIDI 21–108，`--min-midi`／`--max-midi`）；有限 FFT 分辨率使最低音区尤其模糊。结果用于找音组和重复动机，不是完整多声部分离。
- `--start` 指向乐句起点。默认半拍网格仅相对这个起点，若起点不对，后续候选都会错位。脚本不检测准确拍点，也不强行把频谱峰变成声部。

用户明确要求精确扒谱，且混音中无法区分独立旋律时，优先按 [真实分轨与可校订转谱](stem-transcription.md) 处理，再结合已有 MIDI／可靠乐谱核对误检。基础 NumPy 工具不能承担它不具备的能力；不要未经需求就下载大型模型。参考文件、分析 JSON 与编曲理由分别保存。

## 用证据控制改编

1. 比较多个段落的 BPM、重音与乐句长度。不要只凭一个峰选择速度，也不要照抄文字中的 BPM。
2. 先找低音落点、和弦音组与重复乐句，再选择主旋律候选；失真吉他与脉冲波的高次谐波很强。
3. 将证据写成简短说明：哪些音组稳定、哪个八度不确定、哪个回应是新写的。保留多个候选而不是假装每一拍都确认。
4. 先渲染一个完整动机的 8-bit 乐句验证方向，再安排回应、过门、高潮和收束。已有用户认可音轨时，基于它改动，保留旧版。

没有精确谱也能制作“参考动机改编”；它与“忠实逐音翻奏”是不同交付。原曲录音不参与合成时应明确说明，不能因此暗示改编与原作不存在关系。

## 实际听感与输出

- 厚重高潮需要增加低八度／五度支撑、快速琶音与鼓点密度；持续大音量噪声容易盖住主题。
- 包络保护每个音符的起止；PolyBLEP 缓解脉冲波混叠，不代表已经消除所有刺耳感。
- 预览版淡出与可循环母版分别导出；MP3 文件不自动保证无缝循环。网页可将音轨解码到 Web Audio buffer 再按音频时钟循环，或使用合适的无损母版。
- 三轮试听包含实际接缝，不仅拼接几张音量报告。统计只报告测得的量，不把“边界相差小”当作听起来必然自然。

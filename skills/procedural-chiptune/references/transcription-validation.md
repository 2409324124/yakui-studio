# 转谱验证与能力边界

历史验证使用一段约 89 秒的合唱与伴奏录音。原始录音、分轨、谱面和逐音分析不随本技能分发；以下只保留方法与限制，不能作为当前输入的测量结果。

Demucs `htdemucs` 实际产生 drums、bass、other、vocals 四类轨道。Basic Pitch ONNX 在混音、vocals 与 other 上均可产生复调候选，但伴随短碎音、同时八度与伴奏泛音混淆。pYIN 在合唱上只得到少量短音：单声部假设不适合多人同时演唱。分离成功不代表转谱准确，候选数量也不是准确率。

对需要忠实旋律的片段，用可靠谱面与实际录音对齐来校订；无法确认的回应保留 unassigned 或标明新创。不能将频段或高低音分组称为准确的独立旋律分离。

脚本的已知 MIDI 28（E1）合成夹具验证了低音搜索通路；冲突角色窗口保留 unassigned 和两个候选角色；显式修改保存 before 与理由；量化增加派生字段而不删除原始秒时刻与弯音。这些是功能验证，不是对真实歌曲准确率的承诺。

历史 CPython 3.12 隔离环境验证了 Basic Pitch 0.4.0 的正常 ONNX Model 导入与短人声推理。详细依赖组合见 [真实分轨与转谱](stem-transcription.md)；不同系统仍须验证当前运行环境。不要通过改第三方源码或临时 shim 掩盖安装失败。
